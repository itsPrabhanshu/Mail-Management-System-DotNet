# Mail Management System

Mail Management System developed using .NET and C# with MySQL as the backend database. The application enables users to send and manage messages through features such as Inbox, Sent Messages, Drafts, Important Messages, and User Profile Management.

## Features

* User Registration & Login
* Send Messages
* Inbox Management
* Sent Messages
* Draft Messages
* Important Messages
* User Profile Management
* Secure Logout

## Tech Stack

* .NET
* C#
* MySQL
